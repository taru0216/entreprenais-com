グリーンAIクラウド「EntreprenAIs Cloud」提供開始

樽石デジタル技術研究所合同会社（TDRI）は本日、超高速・超省電力を両立するグリーンAIクラウド「EntreprenAIs Cloud」の提供を開始しました。自社グリーンデータセンターで稼働し、電力起源の透明性を前提に設計されています。

大脳AI × エージェント脊髄反射技術のハイブリッドアーキテクチャ

EntreprenAIs Cloud は、人間の神経系になぞらえた2層構成を採用しています。複雑な判断・生成を担う「大脳AI」（自社グリーンデータセンター内で稼働するローカル LLM によるじっくり思考）と、定型的な応答を LLM 推論なしで CPU 上で完結させる「エージェント脊髄反射技術」（瞬時応答）を、ひとつの会話の中でシームレスに切り替えます。反射で足りない問いは、そのまま大脳AIへ引き継がれ、会話が途切れることはありません。

この切り替えを支えるのが、設計図（SKILL.md）を実行プログラム（skill.py）へ変換する自社独自のコンパイル技術です。大脳AI が一度じっくり考えて書いた設計図を、CPU だけで動く軽量な実行体へと変換することで、高速化のもう一つの柱を担っています。現時点では人と並走しながら進める半自動の工程であり、対応できる範囲を運用しながら段階的に広げています。

自社グリーンデータセンターによる電力起源の透明性

EntreprenAIs Cloud は、太陽光自家発電と再エネ電力契約による電力で運用する自社グリーンデータセンターの上で動作します。外部クラウド LLM への通信往復や他社データセンターの電源構成に依存しない構成とすることで、電力起源を自社で完結させ、対外開示・証跡整備を前提とした透明性のある「グリーン」運用を目指しています。

再エネ電力には出力・供給量の制約があります。EntreprenAIs Cloud のハイブリッドアーキテクチャは、この制約の中で消費電力を極限まで下げる必要から生まれたものであり、「超高速」と「超省電力」の両立は、制約を起点とした設計思想の帰結です。

数値・訴求表現に関する注記: 「超高速」「超省電力」「エージェント脊髄反射技術の応答時間」等の数値・性能表現は、現時点における自社内実測値・自社計測条件に基づくものであり、すべてのリクエスト・利用環境における性能を保証するものではありません。「実質再エネ100%」等の電力起源に関する表現は、自社太陽光発電設備の自家発電および再エネ電力契約に基づくものです。計測条件・開示粒度については、対外公表の透明性向上に向けて継続的に整備を進めています。詳細はアーキテクチャ・グリーンの各セクションもあわせてご参照ください。
