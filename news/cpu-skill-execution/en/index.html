EntreprenAIs Establishes Proprietary Technology
to Execute Agent Skills on CPU Only

Taruishi Digital Technology Research Institute LLC (TDRI) has established a proprietary technology within EntreprenAIs to execute agent skills in combination with ultra-lightweight models that operate on CPU only.

Previously, running agent skills was assumed to require a model of considerable size. With this new proprietary technology, it is now possible to run agent skills in combination with ultra-lightweight models that operate on CPU only, significantly expanding the range of available operating environments.

With this technology, many EntreprenAIs skills — including scheduled operation skills such as Daily Briefing and End of Day — now run on ultra-lightweight local LLMs. In addition, we have realized the ability to have an assistant permanently resident in the chatroom, enabling a local LLM to handle routine room tasks on behalf of users. This marks a major step forward toward deployment in a wider variety of contexts.

EntreprenAIs has consistently been committed to running agents autonomously with limited resources. This initiative gives concrete form to that policy and is positioned as an important milestone in broadening the product's reach.

Further details on the technology and future developments will be announced in due course. For inquiries or implementation consultations, please contact us.
