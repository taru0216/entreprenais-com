绿色AI云「EntreprenAIs Cloud」正式上线

樽石数字技术研究所合同公司（TDRI）今日正式推出兼具超高速与超低功耗的绿色AI云「EntreprenAIs Cloud」。该服务运行于自有绿色数据中心，以电力来源的透明性为设计前提。

「大脑AI」× 「智能体脊髄反射」技术的混合架构

EntreprenAIs Cloud 借鉴人体神经系统的两层结构：负责复杂判断与生成的「大脑AI」（在自有绿色数据中心内运行的本地大模型，进行深度思考），与无需大模型推理、仅在 CPU 上瞬时完成定型响应的「智能体脊髄反射」技术。两者在同一场对话中无缝切换——当反射响应无法满足需求时，会话会自动交由大脑AI接手，对话不会中断。

支撑这一切换的，是我们自主研发的编译技术：将大脑AI深思熟虑后写出的「设计图」（SKILL.md）转换为仅需 CPU 即可运行的轻量级可执行程序（skill.py），这是实现高速化的另一大支柱。目前该流程仍为人机协同的半自动阶段，我们正持续扩大其可处理的范围。

自有绿色数据中心带来的电力来源透明性

EntreprenAIs Cloud 运行于依靠太阳能自发电与可再生能源购电合同供电的自有绿色数据中心。通过消除对外部云端大模型的往返通信，以及对其他公司数据中心电源结构的依赖，我们致力于将电力来源完全掌控在自身范围内，并以可验证的信息披露为前提，追求透明的「绿色」运营。

可再生能源在出力与供应量上存在客观制约。EntreprenAIs Cloud 的混合架构正是在这一制约下、为将功耗降至极限而催生的成果——「超高速」与「超低功耗」的兼得，是围绕这一约束条件进行设计后的必然结果，而非事后附加的独立功能。

关于数值与宣传表述的说明：「超高速」「超低功耗」以及「智能体脊髄反射」技术响应时间等性能表述，均基于我们自身的内部实测数据与自定测试条件，并不保证在所有请求或使用环境下均能达到相同性能。「实质可再生能源100%」等电力来源相关表述，基于自有太阳能发电设施的自发电及可再生能源购电合同。我们将持续完善测量条件与信息披露的透明度。详情请参阅首页的架构与绿色相关章节。
