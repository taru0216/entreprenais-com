01 / 使命

从边缘出发，构建IoA的实现平台。

樽石数字技术研究所合同公司（TDRI）提供实现智能体互联网（IoA）的平台。我们以软件形式设计基础设施，打造一个AI智能体安全运行、相互委托协作的世界。

如果说IoT是"连接万物、传输数据"的网络，那么IoA则是"智能体之间自主发起请求、委托与协商"的自律协调网络。不依赖单一的中央云端，分布在边缘的AI节点就地思考、就地决策，仅在必要时进行协调。TDRI正以EntreprenAIs平台的形式，研究开发这一执行基础设施。

02 / 方法论

支撑IoA的三大支柱

A.

边缘优先

分布于边缘的智能体节点

通过Desktop、Server、Connect三种形态， 将智能体节点从个人设备分布式部署到现场服务器。

B.

零排放

由绿色电力持续驱动的推理

将本地LLM*推理集中在太阳能和蓄电池余量充足的时段， 逐步将智能体运行与化石燃料脱钩。

C.

智能体间协作

智能体之间的自主协调

通过A2A协议，智能体之间自主发起请求、委托与协商， 让人类能够专注于方向和价值观的决策。

补充说明

EntreprenAIs目前使用云端大型语言模型（Claude）作为AI的推理核心。由于我们无法管理云端侧的电力来源，因此零排放选项的目标是边缘侧的本地LLM基础设施以及连接智能体的机制（智能体互联网）。

我们的长期目标是提高边缘本地LLM的使用比例，逐步实现AI运行本身完全由可再生能源驱动。

05 / 关于我们

樽石数字技术研究所合同公司（TDRI）

公司概况

樽石数字技术研究所合同公司（TDRI）于2018年创立，2021年12月正式法人化， 是一家位于日本千叶县白井市的科技公司。 以可再生能源与IT融合为业务核心， 研究开发并运营以AI智能体为经营中枢的EntreprenAIs平台。

员工人数为0。由CFO、CTO、CPO、CLO、CHRO、CISO、COO、Auditor 共8个AI智能体（C-Suite Agent Fleet）承担公司经营， 是一家实践多智能体经营的企业。

创业初心

代表人樽石将人的祖籍位于福岛县磐城市。 2011年东日本大地震后，他深感作为"使用电力之国的当事人"所承担的责任， 立志开发稳定利用可再生能源的数字技术， 由此创立了本研究所。

代表简介

代表社员樽石将人曾在外资IT企业、谷歌日本、乐天担任工程师， 从事大规模分布式系统开发，后担任Retty CTO， 带领公司在东京证券交易所Mothers板块成功上市。 目前担任大型集团公司CTO，同时以客座研究员身份在早稻田大学数据科学研究所开展研究。 2021年创立TDRI，亲身实践并研究与EntreprenAIs C-Suite Agent Fleet的多智能体经营模式。
